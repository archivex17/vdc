⚜️ FIXUS

The Spell of Targeted Character Correction

Book of Brohmu

Official Vyni D Codex Spell

Purpose

Fixus applies precise corrections to a selected character or visual detail while preserving the original composition, artwork, and surrounding elements.

Invocation

Fixus + Character Name

Example: Fixus Jason

Correction Protocol

  • Identify the specified character.
  • Use the official character reference.
  • Apply corrections identified by Differentation.
  • Correct facial features, hair, or proportions.
  • Maintain the original character pose.
  • Preserve the established art style.
  • Inspect the result for unintended changes.

Preservation Rules

  • Only edit the specified character.
  • Preserve all unrelated characters.
  • Do not change backgrounds or scenery.
  • Do not alter speech bubbles or dialogue.
  • Do not reposition comic panels.
  • Preserve original colors and shading.
  • When using a 2x2 collage, edit only the top-left image unless otherwise instructed.

Default Output

A corrected version of the selected image with the target character matching their official reference design while preserving all unrelated visual elements.
